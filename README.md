# minaeliaa.github.io

Hand-coded static rebuild of Mina Elia's Framer portfolio (https://mina-designer.framer.website/).

- `index.html` — the whole site (critical CSS inlined), `404.html`
- `js/main.js` — menu, scroll reveals, scroll-linked word reveal, pricing dropdown/toggle, FAQ, card tilt
- `fonts/` — DM Sans + Hanken Grotesk, self-hosted WOFF2 subsets
- `img/` — AVIF/WebP with JPG/PNG fallbacks at 1x/2x/3x

Served by GitHub Pages from the `main` branch root.
